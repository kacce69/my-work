# Margot — Reels avec son

- `kit/` : de quoi fabriquer un Reel vertical (1080 × 1920) où Margot parle : `sh kit/preparer.sh`, puis `python3 kit/reel.py kit/exemple.json sortie.mp4`.
- `reels/` : les vidéos publiées sur Instagram (une par jour de campagne), avec leur image de couverture.

La voix est générée sur place avec Kokoro (voix française `ff_siwis`), sans service payant.
